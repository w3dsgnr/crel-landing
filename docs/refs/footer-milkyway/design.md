# Футер «Contacts» — референс milkyway

## 1. Identity

Плакатная типографика на светлой карточке, вставленной в тёмную раму. Один жест
несёт всё: **гигантский строчный вордмарк, у которого видна только верхняя половина** —
край вьюпорта/карточки срезает его, и слово читается как объект, а не как текст.
Тон — швейцарский/итальянский модернизм: гротеск, моно для реквизитов, ноль декора,
воздух вместо линий. ✅

«ONE brand thing»: полукадрированный вордмарк на всю ширину. Всё остальное — служебное.

## 2. System (наблюдение → наши токены)

| Роль | Референс | Crel (слой v4) |
|---|---|---|
| Рама | почти чёрный, зелёно-чёрный ~`#050a06` ✅ | `.layer-v4-invert` `#0a0a0a` (та же плоскость, что hero) |
| Карточка | светло-серый ~`#e4e5e4` ✅ | `--color-bg-mist` `#f5f5f7` (сцена карточек) |
| Текст основной | чёрный ~`#0d0d0d` | `--color-ink` `#1d1d1f` |

| Hairline под контактами | ~`#cfcfcf`, 1px ⚠️ | `--color-line` — но правило v3.5: линии только внутри мокапов → **заменить воздухом или оставить как единственную линию блока** (см. Do/Don't) |

| Отступ карточки от рамы | ~60px по бокам и сверху на 2000px → ~3% ✅ | `clamp(16px, 3vw, 60px)` |

Типографика ✅:
- Заголовок «CONTACTS»: гротеск, uppercase, medium, ~110px на 2000 → `clamp(3rem, 5.5vw, 7rem)`, tracking −0.02em, leading 1.
- Реквизиты: моно, uppercase, ~14px, пары `label(muted) value(ink)`, разнесены по правому краю равными колонками.
- Контакты (телефон, e-mail): гротеск, uppercase, ~32px → `clamp(1.25rem, 1.8vw, 2rem)`, под каждым hairline на ширину строки.
- Вордмарк: гротеск lowercase, ~330px на 2000 → у нас **~34vw** (c:rel_ короче milkyway — кегль подобран так, чтобы слово легло на всю ширину карточки), tracking −0.04em, чёрный, начинается у левого поля карточки; **видна ≈50% высоты** — обрезка нижним краем.

Пространство: три яруса — шапка (заголовок + реквизиты) / контакты / вордмарк; между ярусами ~150px на 2000 → `clamp(3rem, 7vw, 9rem)`.

## 3. Components

- `FooterCard` — светлая карточка с верхним радиусом, `overflow-hidden` (режет вордмарк).
- `MetaPair` — моно `label · value` (STUDIOS · ROME, MILAN).
- `ContactLine` — крупная uppercase строка + hairline.
- `Wordmark` — `aria-hidden` display-строка, `line-height: 1`, `translateY(50%)` или отрицательный `margin-bottom` = −0.5em: видна верхняя половина.

## 4. Layout

- Рама: full-bleed тёмная, `padding-top ~3vw`, боковые поля равны верхнему; карточка тянется до низа страницы (обрезка вордмарка = край карточки = край страницы).
- Внутри карточки: контейнер с полями ~2.5vw; шапка — grid 1fr/auto (заголовок слева, реквизиты справа в 3 колонки); контакты — inline-flex с gap ~64px; вордмарк вне контейнера, на всю ширину карточки.
- Мобиль ❓ (не показан): реквизиты в столбик под заголовком, контакты в столбик, вордмарк тем же приёмом (34vw на 375 → 128px, срез 50%).

## 5. Reconstruction (Crel)

Стек: Tailwind v4 утилиты + 2–3 правила в globals.css (вордмарк, карточка).
Quick wins: всё статично, без JS. Tricky: срез вордмарка — `overflow-hidden` на карточке + `-mb-[0.5em]`/`translate-y-1/2` на строке; шрифт display грузится — CLS не будет, если высота задана через `line-height:1` + `font-size` в vw.

Маппинг контента Crel: заголовок → «Contact» (или «c:rel_» — нет, вордмарк уже внизу; заголовок «Contact»); реквизиты → `footer.legal` (адрес/рег. номера — сейчас [VERIFY]-плейсхолдер, разбить на пары «studio · Zurich» / «reg. · […]» / «vat · […]»); контакты → `footer.email` (телефона в контенте нет — одна строка); ссылки nav/legal → мелкий моно/строчный ряд между контактами и вордмарком или в шапке справа; copyright → рядом с реквизитами. Вордмарк → `c:rel_` (курсор без мигания — статичный, как в референсе всё статично; либо `_` в акценте — единственный цвет блока).

Confidence: композиция ✅, цвета ⚠️ (сжатие JPEG), мобиль ❓.

## 6. Do / Don't

Do: один цветовой акцент максимум (синий `_` в вордмарке); воздух вместо разделителей; моно только для реквизитов; вордмарк строго обрезан на ~50% (меньше — не читается, больше — теряет «объектность»); карточка тем же радиусом, что низ hero — страница закольцована.
Don't: не добавлять hover/моушн (блок — точка покоя после финала); не ставить hairline'ы там, где референс их не имеет; не переносить вордмарк на две строки; не красить карточку в синий финала — рама должна быть тёмной, иначе теряется контраст «плакат в раме».

## Open questions
- Телефон: в контенте нет — строка одна (e-mail) или добавить [VERIFY]-плейсхолдер? Решение: одна строка.
- Рама: чёрный (bookend с hero) vs синий финала. Принято: чёрный, чтобы карточка читалась как в референсе; финал → чёрная рама → светлая карточка.
