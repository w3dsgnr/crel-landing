## TL;DR

Секция-колода: чёрная сцена; стартовый кадр — пустой слот кучи, вся колода
сложена стопкой снизу шапками-названиями (замена чипсов). По скроллу карта
выезжает вверх и ложится в кучу поверх предыдущих со своим наклоном (±2.5-4.5°)
— края нижних карт выглядывают из-под верхней, как физическая колода. Внутри
карточки минимум — лейбл, тонкая линейная иконка, editorial-заголовок, лид.
Наша адаптация: карточки `{colors.card-bg}` (#2E7CF6), референс-лайм не переносится.

## 1. Visual identity

### 1.1 Surface description

**Personality**: графичный, плакатный, тактильный («колода карт»), сдержанно-игривый.

**Mood**: уверенная простота; физика стопки даёт ощущение управляемого объёма.

**Detectable stylistic references**: React Bits ScrollStack; editorial-карточки в духе
поздних brutalist-лендингов (одна заливка, крупный радиус, лёгкий наклон в движении).

**Information density**: минималистичная — одна мысль на карточку.

**Implicit positioning**: продуктовая аудитория; подача «пять аудиторий — пять карт».

**Confidence**: ✅ high

### 1.2 Brand voice / Atmosphere

Стек ведёт себя как колода физических карт на тёмном столе: карточки непрозрачные,
одноцветные, без картинок — весь смысл несут типографика и одна линейная иконка.
Глубина создаётся не тенью и не градиентом, а перекрытием: каждая следующая карта
буквально ложится на предыдущую, и от предыдущей остаётся ровно строка названия.
Это превращает навигацию в физику: список названий — не меню, а видимый край колоды.

Цвет работает блоком: одна заливка на всю карту, контраст только чёрное/цвет.
Иконки — тонкий штрих, почти чертёжный: они маркируют карту, не иллюстрируют её.

### 1.3 The "ONE brand thing"

- **The thing**: куча непрозрачных одноцветных карт с разными наклонами, в
  которую по скроллу складывается нижняя стопка (peek `{spacing.scale[6]}` = 48px).
- **Why it carries the brand**: убери перекрытие — останется обычная карусель;
  именно «колода» делает секцию узнаваемой.
- **How everything else supports it**: одна заливка `{colors.card-bg}` у всех карт,
  отсутствие картинок и теней — ничто не спорит с физикой стопки.
- **Where it appears (and where it deliberately doesn't)**: только секция use cases;
  остальной лендинг стеков не использует.

*Confidence*: ✅ high

В референсе карты лаймовые с тёмным текстом; по решению проекта (акцент v4 — синий,
чужие цвета референсов не переносятся) карты — `{colors.card-bg}`, текст белый.

### 2.2 Typography

- **Family**: гротеск проекта `--font-grotesk` *(✅ high)*

| Token | Size | Weight | Tracking | Use |
|---|---|---|---|---|
| `section-display` | clamp(2rem,3.6vw,3rem) | 500 | −0.02em | заголовок секции |
| `card-label` | 0.8125rem | 500 | +0.14em, uppercase | шапка-название карты |
| `card-title` | clamp(1.75rem,3vw,2.75rem) | 500 | −0.015em | заголовок кейса |
| `card-body` | 1rem | 400 | 0 | лид кейса |

Uppercase + широкий трекинг живёт ТОЛЬКО в шапках карт — в остальной типографике
проекта его нет, это локальный маркер стека.

### 2.3 Spacing

- Base 4px; внутренние отступы карты ~28-32px; peek стопки `{spacing.scale[6]}` (48px).

### 2.4 Radii

- `card`: 28px — крупнее v4-лестницы (26px) на витринный шаг; единый на все карты.

### 2.5 Elevation system

| Level | Name | Treatment | Use |
|---|---|---|---|
| 0 | Flat | чёрная сцена без декора | секция |
| 1 | Overlap | перекрытие карт + едва заметная тень кромки `0 -8px 24px rgb(0 0 0 / 0.25)` | стопка |

Глубина — перекрытием, не тенями: тень только у кромки наезжающей карты, чтобы
отделить синее от синего.

#### Decorative depth (non-functional)

Тонкая окружность-«пузырь» (outline 1px) — единственный декор референса: одна на
карту, смещена от центра, не пересекает текст. Лёгкий наклон карты (±2-4°)
в момент проезда — опционально, в статике карты ровные.

### 2.6 Borders

- Бордеров нет; линия существует только как штрих иконок и декор-окружность.

## 3. Components Inventory

### 3.1 Generic components

#### stack-card
- **Что это**: карта кейса `{rounded.card}` (28px), заливка `{colors.card-bg}`,
  вертикальной ориентации, но шире референса — почти квадрат (aspect ≈ 1:1.1)
- **Состав**: шапка (label uppercase) → иконка → низ: заголовок + лид (+ чек-строки
  компактно, см. Open Questions)
- **Confidence**: ✅ high

#### card-icon
- **Что это**: линейный глиф в верхней зоне карты под шапкой; размер 40px,
  штрих 1.5px цветом `{colors.card-line}`, без заливки
- **Роль**: чертёжная метка кейса (см. сигнатурный компонент «глифы» в 3.2)
- **Confidence**: ⚠️ medium

### 3.2 Signature components

#### Scroll stack («колода»)
- **What it is**: стартовый кадр — пустой слот кучи, колода сложена стопкой
  снизу (шапки всех карт видны — замена чипсов-табов); по скроллу карта k
  выезжает вверх и ложится в кучу поверх предыдущих со своим наклоном
  (±2.5-4.5°, набирается в полёте) — края нижних выглядывают из-под верхней
- **Why it's signature**: навигация = физический край колоды; куча с наклонами
  делает стек «ручным», а не механическим
- **Composition**: pinned-сцена + прогресс скролла → позиции карт (N переездов);
  непрозрачные заливки обязательны (перекрытие держит глубину); мягкая тень по
  контуру отделяет синее от синего
- **Where it appears**: только use cases
- **Confidence**: ✅ high

#### Линейные иконки-глифы
- **What it is**: абстрактная геометрия штрихом 1.5px `{colors.card-line}`: не
  иллюстрации, а чертёжные метки (в референсе: три линии, ромб-контур, окружность)
- **Наши глифы** (по кейсу): wallets — скруглённый прямоугольник с точкой;
  exchanges — две встречные стрелки-шеврона; neobanks — окружность с горизонтальной
  хордой; remittances — длинная стрелка через две вертикальные засечки (коридор);
  payrolls — три горизонтальные линии разной длины (ведомость)
- **Confidence**: ⚠️ medium — глифы спроектированы, в референсе видны три образца

## 4. Layout & Composition

### 4.1 Grid & containers

- Стек центрирован в контентной сетке (`max-w-[1200px]`), ширина карты
  ~min(600px, 92vw); заголовок секции над стеком, по центру, лейбл «03: use cases»
  удалён по решению.

### 4.2 Composition patterns

- Pinned-сцена (существующий Wembi-скраб секции) → прогресс делится на N
  сегментов; сегмент k — полёт карты k из нижней стопки в кучу.
- Заголовок секции живёт В слоте кучи (z под картами), х2-масштаб
  (clamp(4rem,7.2vw,6rem)), на desktop две строки с разрывом перед «that»;
  карты по мере скролла перекрывают текст, края букв выглядывают из-за колоды.
  Появление — split-text (React Bits): посимвольный подъём из-под базовой
  линии, stagger 20ms, один раз при входе в вьюпорт; на mobile заголовок
  обычным потоком над стопкой в базовом размере.
- Состояния карты: «в нижней стопке» (виден верхний peek, ровная) → «в полёте»
  (движется вверх, наклон набирается по фазе) → «в куче» (лежит поверх
  предыдущих со своим наклоном; z растёт с индексом).

### 4.3 Responsive behavior

#### Breakpoints

| Name | Width | Key changes |
|---|---|---|
| Mobile | < 768px | скраб выключен (существующее правило): CSS-sticky куча — все карты липнут в одну точку, наклон статический, следующая наезжает обычным скроллом |
| Desktop | ≥ 768px | pinned-сцена, карта ~560px |

❓ low — mobile в референсе не показан; спроектировано по механике sticky-стека.

#### Touch targets

- Шапки перекрытых карт кликабельны как табы (существующий goTo) — высота peek
  56px ≥ 44px, проходит.

#### Collapsing strategy

- Стопка шапок сверху: до 4 шапок × 56px + карта ~520px — бюджет pinned-сцены
  на 900px вьюпорте с шапкой сайта (~104px) и заголовком секции — впритык;
  допускается peek 48px и карта 480px на невысоких экранах (vh-капы).

### 4.4 Image behavior

Картинок нет (решение): единственная графика — линейные SVG-глифы и
декор-окружность. Рендеры из public/assets/usecases в этой версии не используются.

## 5. Reconstruction Notes

### Suggested stack

**Существующий компонент UseCases.tsx**: сохранить pinned-обёртку, ScrollTrigger
и goTo/Lenis; заменить содержимое сцены на стек карт, позиции карт вести от
progress (GSAP quickSetter или timeline со scrub). Tailwind v4 + токены `.layer-v4`
с модификатором `.layer-v4-invert` на секции (чёрная сцена уже реализована для hero).

### Quick wins

- Механика прогресса и клика-докрутки уже написана (goTo, сегменты).
- Чёрная сцена — готовый `.layer-v4-invert`.
- Контент карт — те же useCases.tabs (id → label, title, body, checks).

### Tricky bits

- Два режима позиций (нижняя стопка / центр / шапка сверху) — считать от высоты
  сцены в px (ResizeObserver или расчёт в onUpdate), не в vh-магии.
- Непрозрачность карт обязательна — полупрозрачный синий разрушит перекрытие.
- AA лида на #2E7CF6: белый ~4.0:1 — либо лид чисто-белым 0.9375rem+, либо
  заливка `{colors.card-bg-deep}`; проверить check_contrast.py на полировке.
- Reduced-motion: статичная колонка полных карт без стека.

### Implicit states to define

- Hover шапки перекрытой карты (лёгкое поднятие/осветление).
- Фокус-обводка при клавиатурной навигации по шапкам (accent-bright на синем не
  работает — использовать белую).

## 6. Do's and Don'ts

### Do

- **Карты только непрозрачные** `{colors.card-bg}` — перекрытие и есть глубина.
- **Шапка-название — единственная навигация**: uppercase + трекинг 0.14em,
  peek 56px, кликабельна (роль табов сохраняется, aria — тоже).
- **Иконки — штрих 1.5px `{colors.card-line}`**, абстрактная геометрия; не
  заливки, не эмодзи, не иллюстрации.
- **Одна декор-окружность на карту максимум**, не пересекает текст.
- **Все карты одного цвета** — различие карт несут названия и глифы, не палитра.
- **Стартовый кадр обязан показывать названия всех пяти карт** — это контракт
  «названия вместо чипсов».

### Don't

- **Не переносить лайм референса** — карты синие, акцент v4 (#2E7CF6).
- **Не класть картинки/рендеры в карты** — типографика + глиф, всё.
- **Не разводить карты тенями** — только кромочная тень наезда (см. 2.5).
- **Не делать карты полупрозрачными и не блюрить** — колода из стекла не работает.
- **Не оставлять лейбл «03: use cases»** — удалён по решению; заголовок секции
  остаётся.
- **Не вводить uppercase-трекинг за пределами шапек карт.**
